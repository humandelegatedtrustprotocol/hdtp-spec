## `B64url`

Bytes, as base64url without padding, in exactly this alphabet. Every answer spells them this way, and every wire object of the specification is read this strictly: an envelope's members, an export's certificates, a signing request. A library argument outside those objects is also read with padding or the standard alphabet, and never with whitespace (CONTRACT §0); a card's certificate loses its spaces, tabs, CRs and LFs before it is read (`card_decode`).

Type: `string`; pattern `^[A-Za-z0-9_-]*$`.

## `Fingerprint`

`"sha256:" + b64url(SHA-256(SPKI))`.

Type: `string`; pattern `^sha256:[A-Za-z0-9_-]{43}$`.

## `InstantIn`

An RFC 3339 UTC instant as an argument, in the one grammar every port reads: upper-case T and Z, no offset, `.` alone before a fraction of a second, which is allowed and DROPPED, because the boundary is whole seconds.

Type: `string`; pattern `^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}(\.[0-9]+)?Z$`.

## `SigningRequest`

A host's signing request (SPEC §9.1), the members of its form as the form carries them: every one a string. Bounds are bytes, and characters (Unicode scalar values) for `recipient`; the whole body is bounded by the wallet's host.

| Member | Type | Required | Bounds | Description |
|---|---|---|---|---|
| `csr` | `string` | yes | at most 4096 characters | base64url PKCS #10: the recipient's key and the endpoint. |
| `purpose` | `"renew"` \| `"move"` | yes |  |  |
| `expect_root` | [`Fingerprint`](#fingerprint) | yes |  |  |
| `root_cert` | `string` | no | at most 4096 characters | base64url DER of the root, if the host holds it. |
| `redirect` | `string` | yes | at most 2048 characters | Where the answer goes: https, or http to a loopback host; no userinfo, no fragment. |
| `state` | `string` | yes | pattern `^[A-Za-z0-9_-]{43}$` | 32 random bytes, base64url, echoed back. |
| `recipient` | `string` | yes | at most 200 characters | What the host calls itself: shown as its claim, never trusted. |
| `valid_days` | `string` | yes | pattern `^(?:[1-9][0-9]?\|[12][0-9]{2}\|3[0-8][0-9]\|39[0-8])$` | The validity the host asks for, 1 to 398, as the form's text: a suggestion; the person chooses. |
| `expires` | `string` | yes |  | RFC 3339 UTC, after now and at most ten minutes ahead. |

No other members are allowed.
