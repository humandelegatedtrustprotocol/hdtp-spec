# The HDTP name guard's list: what no tracked file of an HDTP or BatonDeck repository may carry, in
# its path or in its text. One list, byte-identical in every repository whose gate runs the guard;
# this copy, in hdtp-spec, is the canonical one, and each other copy is compared with it whenever
# hdtp-spec is checked out beside that repository.
#
# The guard reads the TREE (`git ls-files`), never history. It skips binary files (any NUL byte),
# built and vendored output (dist/, node_modules/, target/) and go.sum, whose lines are hashes, and
# the dated records a `frozen` manifest lists, for as long as they are the bytes it lists.
#
# Lines, after comments (#) and blank lines:
#
#   name <word>                       forbidden, spelled exactly as written, wherever it occurs:
#                                     inside a longer word, after a digit, an underscore or an
#                                     escape, in a path. The old name was only ever written three
#                                     ways, all lower-case, capitalised and all upper-case, and
#                                     each has its line. Any other casing of the four letters is two
#                                     words joined (stepAction, keepActive, HTTPAction) and passes:
#                                     matched without regard to case, the rule refused those
#   except-after <prefix>             ...unless the letters right before it are <prefix>, in any
#                                     case. This is how English words pass (impact, Compact)
#   retired <regular expression>      forbidden, case-sensitive: a name of a behaviour HDTP does not
#                                     have. Written to run unchanged in JavaScript and in Go (RE2)
#   allow <repo> <path> <text>        in repository <repo> (its origin remote's name), file <path>,
#                                     a forbidden name inside the exact <text> is allowed. An entry
#                                     whose text is not in its file fails as stale, in that
#                                     repository's gate and in no other; an occurrence inside a
#                                     longer entry's text is the longer entry's
#   once <repo> <path> <text>         as allow, and <text> must occur exactly once in that file and
#                                     in no other file of the repository
#   frozen <repo> <manifest>          in repository <repo>, the files <manifest> lists are dated
#                                     records: a review's findings, a captured run, a design as
#                                     it was decided. They are true of their day, code cites them
#                                     and a later audit reads them, so they are kept byte for byte
#                                     and the guard reads neither their text nor their path.
#                                     <manifest> is a tracked file of that repository holding one
#                                     `<sha256>  <path>` per line, as `shasum -a 256` writes it,
#                                     and nothing else: no comment, no blank line, no path twice.
#                                     Its own text is not scanned, because it is that list; a
#                                     manifest with any other line in it is refused whole, and is
#                                     then scanned like any file. Adding a line is the act a
#                                     reviewer reads. What holds a record to its line:
#                                       - a file is exempt only while its bytes hash to its line.
#                                         Edited, it is scanned like any other file, and its
#                                         entry fails as well: a record is replaced by a new line
#                                         in the manifest, or not at all;
#                                       - a listed path that is not a tracked file fails as stale;
#                                       - a file beside the records that the manifest does not
#                                         list is scanned as always: nothing new hides there;
#                                       - a manifest that is missing or lists nothing fails, in
#                                         that repository's gate and in no other. Where no
#                                         `frozen` line names it, such a file is only a file.
#
# The guard fails when it reads fewer than three names or ten retired names: then the reader is
# broken, not the tree.

name pact
name Pact
name PACT
except-after im
except-after com
